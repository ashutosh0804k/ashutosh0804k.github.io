Bug log

Four bugs I am glad I caught, written the way I would file them.

BUG-001 Fixed Ubisoft live title

Sync bugs that only appeared at certain pings

Symptom
Peer-to-peer sync broke only at specific latencies, so nobody could reproduce it on demand.
Fix
Co-built a network simulation tool that dials in latency and packet loss until the bug shows up every time.
Impact
8+ hours saved per investigation.
BUG-002 Fixed spx-forecast

A merge silently dropped data

Symptom
The April forecast was off by about 770 points with no error anywhere.
Cause
An inner join removed every row after January 2025. Found by checking the last date of each input.
Fix
Completed the dataset and added tests for date gaps and future leakage.
BUG-003 Fixed selenium-pytest-framework

Tests passed with a broken API key

Symptom
The API suite stayed green even when every request returned 401.
Cause
Tests checked only response time and content type.
Fix
Every test asserts a 200 first. All 12 API tests now fail with a bad key.
BUG-004 Prevented selenium-pytest-framework

Login blocked by a breach popup

Symptom
Chrome's breached-password dialog covered the page after login and swallowed clicks.
Fix
Disabled password leak detection in the driver setup before it could flake in CI.
